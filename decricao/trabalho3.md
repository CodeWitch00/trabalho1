**Objetivo:** Mapear a arquitetura de uma aplicação web do lado do servidor (Back-end) utilizando o padrão MVC e os mecanismos do protocolo HTTP.

**Atividade Assíncrona:**

**Cenário Corporativo:** Você foi contratado como Arquiteto de Software para reestruturar uma aplicação legado e separá-la no padrão **MVC (Model-View-Controller)**.

**Elaboração da Especificação Técnica:**

- Mapeie como as **Views** (JSP/HTML), os **Controllers** (Servlets) e as classes de **Model** interagem no fluxo de autenticação do usuário.
- Descreva como será feito o **Controle de Sessão e Cookies** no servidor para manter o usuário autenticado durante o ciclo de *Request/Response*, embasando-se nos capítulos de controle de estado de **BASHAM** ou **KURNIAWAN**.
