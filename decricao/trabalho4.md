**Objetivo:** Desenvolver uma aplicação web funcional (*CRUD*) integrando o front-end, a camada de controle/regra de negócio e a persistência em Banco de Dados.

**Atividade Assíncrona:**

Desenvolva uma aplicação web completa (Ex: Sistema de Gestão de Usuários/Produtos) que conecte o servidor a um banco de dados relacional.

Implemente as operações fundamentais (**Create, Read, Update, Delete**).

Aplique as camadas do padrão MVC, integrando o acesso ao BD via classe DAO/JDBC (ou equivalente), tratando as requisições e respostas HTTP no servidor.

**Entregável:** Link do repositório no GitHub contendo o código-fonte completo da aplicação, o script SQL de criação do Banco de Dados e o arquivo README.md com as instruções de execução do projeto.
