# Sistema de Gestão de Biblioteca

Interface web para cadastro e visualização de livros de uma biblioteca.

## Tecnologias

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Cadastro de livros
* Visualização do acervo
* Busca por livros
* Resumo do acervo
* Tema claro e escuro
* Layout responsivo
* Recursos de acessibilidade

## Estrutura

```text
biblioteca/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── relatorio.md
```

## Como executar

Abra o arquivo `index.html` em um navegador.

## Objetivo acadêmico

Projeto desenvolvido para demonstrar o uso de **HTML5 semântico, CSS3, responsividade e acessibilidade** no desenvolvimento de uma interface web.
