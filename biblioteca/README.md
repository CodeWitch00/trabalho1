# Sistema de Gestão de Biblioteca (GUI Semântica)

Este projeto é uma aplicação web para gestão de acervo de biblioteca, desenvolvida com foco em **HTML5 semântico**, **CSS3 responsivo e acessível**, e **JavaScript complementar**.

## 📌 Principais Recursos

- **Navegação Dinâmica por Fichas**: Exibição individual da ficha selecionada (ou todas empilhadas).
- **Design Vintage Moderno**: Paleta em bege, azul vintage e vermelho terracota.
- **Campos Limpos com Placeholders**: Exemplos de sugestão exibidos dentro dos inputs.
- **Campos Obrigatórios Destacados**: Asteriscos em vermelho (`.asterisco-obrigatorio`).
- **Tema Claro / Escuro**: Suporte a alternância de tema com persistência.
- **Acessibilidade**: Atributos ARIA, navegação por teclado e contraste ajustado.

## 📁 Estrutura de Arquivos

- `index.html`: Interface principal em HTML5.
- `css/styles.css`: Estilização e tema em CSS3.
- `js/script.js`: Comportamento dinâmico (cadastro, busca, tema e fichas).
- `relatorio.md`: Relatório acadêmico detalhado do projeto.

## 🚀 Como Executar

Abra o arquivo `index.html` em qualquer navegador web moderno.
